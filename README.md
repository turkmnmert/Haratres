Bu proje, Java Spring Boot ve MySQL teknolojileri kullanılarak geliştirilmiş bir e-ticaret sistemi backend uygulamasıdır.
Proje, staj sürecim boyunca öğrenme ve deneyim kazanma amacıyla geliştirilmiştir.

Sistemin temel amacı, bir e-ticaret platformunda bulunması gereken ürün yönetimi, kullanıcı işlemleri ve sipariş süreçlerini yönetebilecek bir backend altyapısı oluşturmaktır.

Projede:

Spring Boot ile RESTful API yapısı kuruldu.

MySQL veritabanı kullanılarak ürün, kullanıcı ve sipariş verileri düzenli şekilde yönetildi.

Katmanlı mimari (Controller – Service – Repository) yapısı benimsenerek temiz, sürdürülebilir ve geliştirilebilir bir kod yapısı elde edildi.

Bu proje, backend geliştirme prensiplerini ve Spring Boot ekosistemini öğrenmek amacıyla hazırlanmış kapsamlı bir staj çalışmasıdır.
